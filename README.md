# Karachi Executive Gym - Frontend

A modern, responsive web application for **Karachi Executive Gym** (Gulshan-e-Iqbal Block 10-A, Karachi) built with Next.js 14, React 18, Tailwind CSS, and Framer Motion.

## Features

- **Zone Switcher:** Interactive view showcasing dedicated fitness zones (Private Ladies Floor, Heavy Iron Zone, Cardio Deck, Boxing & Functional Rig).
- **Facilities & Equipment:** Detailed breakdown of fitness amenities, recovery zones, and coaching credentials.
- **Membership & Pricing:** Transparent breakdown of monthly, quarterly, and annual executive packages.
- **Member Reviews:** Real testimonials with ratings and local context.
- **SEO & Performance:** Fast static prerendering, optimized typography, and rich schema.org structured data.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

```bash
npm run build
npm run start
```

## Deployment

Optimized for 1-click deployment on [Vercel](https://vercel.com).
